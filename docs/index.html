Core Silicon Invariants // Verified Against Retail Titles

  • GP Mixbuffer Scratch Isolation (gp_ep.c): X:$1400–$17FF (mirrored at X:$0C00–$0FFF) is the VP-to-GP input window; DirectSound reuses X:$1440–$14BF (bins 2–5) as I3DL2 scratch RAM. Wet-delta extraction is strictly restricted to b < 2 (FL/FR) at 0.35f paired with 0.65f 4-corner VP HRTF submix gain.
  • Unconditional Hardware 3D Submix + 2D-List Guard (vp.c): Hardware 31-tap HRIR spatialization runs independently of host headphone settings, gated on allow_3d && v < 64 && !stereo && hrtf_handle != 0xFFFF (allow_3d = false for NV_PAPU_TVL2D).
  • Word-Aligned Circular DMA & Bit-14 Aperture (dsp_dma.c): Circular scratch descriptors mask base, offset, and size with ~(item_size - 1) to stop 1.06 s static bursts; offsets with Bit 14 (0x4000) set act as a hardware zero-generator / bit-bucket.
  • Motorola DSP56362 Core Accuracy (dsp_cpu.c): 32K P-RAM, 64K zero-init X-RAM, 2K zero-init Y-RAM + EP factory ATSC A/52A Y-ROM (Y:$0800–$0FFF), 24-bit masking, asymmetric SSH/SSL stack pointers, LC == 0 loop skip, finite-DO spin-wait exemption, and 2-word IR opcache write invalidation.
  • AC'97 Silicon Routing & Resumption (ac97.c, aci.c): LPC IRQ 6 defaults (0x68/0x6C), sparse SO_INDEX (7) level-triggered IRQ aggregation, unconditional civ == lvi primer-buffer re-arming, standalone sequencer-off playback, and additive FL/FR summing.
